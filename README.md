# Humanity Without Borders — website starter

A responsive, multi-page static website inspired by the information architecture of hdfund.org, with independent branding.

## Publish to GitHub Pages
Upload `index.html`, `style.css`, `app.js`, and `pages.json` to the root of your GitHub Pages repository. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`.

## Important before launch
- This is phase 1, not a pixel-perfect copy or fully populated site.
- Donation buttons are intentionally not connected to payment processing.
- Contact forms are non-functional until a secure form service is configured.
- Replace all placeholder descriptions and photographs with owned or licensed assets and verified organizational content.
- No impact figures or claims of operations in particular countries are asserted.
- Replace logo placeholder with your own logo.
- The website uses remote Google Fonts and Unsplash photos; check licensing and availability before launch.
- All pages are accessible via `index.html?page=...` for GitHub Pages compatibility.

## Main-site package
This package is configured for the `humanity-without-borders` GitHub Pages repository. `content/home.json` powers the English homepage. The `/admin/` CMS login is not operational without an external OAuth bridge.
